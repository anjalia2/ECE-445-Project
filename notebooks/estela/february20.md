## Objective

Decide which MCU to use in between ESP32 and STM32

---

## STM32

### Pros

- Very familiar with environment and coding it from personal experience
- More powerful
- More pinouts
- Smaller
- I already own the programmer.

### Cons

- Much more complicated to set up for my teammates, they have to learn the HALL programming library.
- Less possibility of expansion for what we need.

## ESP32

### Pros

- Has possibility of Wi-Fi and Bluetooth extra implementations
- Never used it, can learn new stuff
- Better for my teammates to code since Arduino is much simpler.

### Cons

- Not familiar with it at all, possible source of error
- Not as powerful

Because the coding part is super important, ESP32 was chosen so that it’s easier for my teammates, and so that I can learn how a different MCU works. We chose ESP32 WROOM-N8R2 because it was the first one we found online that had all we needed.
